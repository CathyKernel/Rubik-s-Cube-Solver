How it works: the solver models the cube as a cubie-level group, reduces the state to the subgroup G1 = ЄU, D, R2, L2, F2, B2Ѕ in phase 1 (orientations + middle-layer edges), then finishes with only half turns and U/D quarter turns in phase 2. Both phases run IDA* with BFS-generated pruning tables inside a Web Worker, so the page stays responsive. Solutions average ~22 moves. Everything is computed locally — no network, no dependencies.
